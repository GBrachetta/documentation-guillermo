# G3 Camera Hub

## What's currently working 

1. Install the following on Home Assistant

   - **Go2rtc**
     1. Settings/Apps/Install App/Repositories - Add `https://github.com/AlexxIT/hassio-addons`
     2. Settings/Apps/Install => Search for Go2rtc, install the first option
   - **Webrtc camera** (Install via HACS)

2. Remove the camera from Apple Home

3. The camera will be automatically discovered by Home Assistant: add it

4. Go2rtc will **not yet** see it available to pair under *Add*, but a long *HomeKit stream URL* will be available under *Add => Home Assistant*

5. Add the following in `config` in Go2rtc

   ```yaml
   streams:
       Camera-Hub-G3-C2C0: # The name you want to give your camera
           - homekit://###.###.###.###:#####... # The long URL from step 4
           - ffmpeg:Camera-Hub-G3-C2C0:#audio=aac#audio=opus  # optional audio transcoding - Camera name must match

   log:
       level: trace # Optional
   ```

6. Add a `Manual Card` and configure it as follows:

   ```yaml
   type: picture-elements
   image: >-
     data:image/svg+xml,%3Csvg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 16
     9'/%3E
   elements:
     - type: custom:webrtc-camera
       url: Camera-Hub-G3-C2C0
       mode: webrtc,webrtc/tcp
       style:
         top: 50%
         left: 50%
         width: 100%
         height: auto
         z-index: 0
       ui: false
     - type: state-icon
       entity: binary_sensor.living_room_aqara_g3_motion_sensor
       style:
         left: 25px
         bottom: 0px
   ```

7. Bridge it back to Apple Home

   - Add the following to the config in `go2rtc`

   ```yaml
   homekit:
     Camera-Hub-G3-XXXX:
   ```

   THe complete config will look similar to this:

   ```yaml
     streams:
       Camera-Hub-G3-C2C0: # The name you want to give your camera
         - homekit://###.###.###.###:#####... # The long URL from step 4
         - ffmpeg:Camera-Hub-G3-C2C0:#audio=aac#audio=opus  # optional audio transcoding - Camera name must match

     homekit:
       Camera-Hub-G3-C2C0: # Use the same camera entity name you used above

     log:
       level: trace # Optional
      ```

     After doing this, a new HomeKit device will be automatically created on Home Assistant.
     **Don't add it to Home Assistant**

   - On the iPhone, open **Apple Home => Add accessory => More options** and the new HomeKit device from Home Assistant will be visible there.
   - Add it, use the generic Go2rtc pairing code `19550224` and the camera will be added it.
   - All original functionality should be present again on Apple Home: Camera, 2-way talk, sensors, Alarm panel.

### Still not working great

The *preview* video thumbnail, for example in the `Security` tab or in the zone where the camera was assigned, still falls to MJPEG, so it not always loads, unlike the `RTC` stream on the card.

## Summary by ChatGPT

AQARA G3 — HOME ASSISTANT + WEBRTC + APPLE HOME

### Goal

Have the Aqara Camera Hub G3 available simultaneously in:

- Home Assistant, with a live stream using WebRTC.
- Apple Home, with a working live stream.

The G3 is paired with Home Assistant. Go2rtc acts as a HomeKit proxy and exposes the camera back to Apple Home.

FINAL ARCHITECTURE

Aqara G3 => HomeKit => Home Assistant => Go2rtc => HomeKit proxy => Apple Home

At the same time:

Aqara G3 => Go2rtc => WebRTC => Home Assistant

WHY THIS WAS NECESSARY

The Aqara G3 was initially paired with Apple Home.

It was removed from Apple Home and then paired with Home Assistant using HomeKit.

The resulting Home Assistant camera entity was `camera.living_room_camera_hub_g3_c2c0`

The camera worked in Home Assistant using WebRTC, however, exposing that HA camera through the normal Home Assistant HomeKit Bridge caused the camera to appear in Apple Home without a working live stream.

The solution was to use go2rtc's HomeKit proxy instead of Home Assistant's normal HomeKit Bridge for the camera.

### GO2RTC CONFIGURATION

The working go2rtc configuration is:

```yaml
streams:
  Camera-Hub-G3-C2C0:
    - homekit://192.168.68.54:37369?client_id=xxxxxxx
    - ffmpeg:Camera-Hub-G3-C2C0:#audio=aac#audio=opus

homekit:
  Camera-Hub-G3-C2C0:

log:
  level: trace
```

### IMPORTANT

The actual client_id must be retained. It is masked above as xxxxxxx for this documentation.

### WHAT THE CONFIGURATION DOES

- The homekit:// line imports the G3's existing HomeKit stream into go2rtc.
- The ffmpeg line provides audio transcoding: `ffmpeg:Camera-Hub-G3-C2C0:#audio=aac#audio=opus`
- The homekit section creates a new HomeKit accessory in go2rtc using the same stream.
- The stream name must be identical: `Camera-Hub-G3-C2C0` in both the streams section and the homekit section.

### IMPORTANT PAIRING CONCEPT

- The G3 itself is paired with Home Assistant.
- Apple Home is NOT paired directly to the G3.
- Instead, Apple Home is paired to the HomeKit accessory created by go2rtc.

Therefore:

G3 => Home Assistant => go2rtc => Apple Home

### ADDING THE GO2RTC CAMERA TO APPLE HOME

1. Add the following to the go2rtc configuration:

     ```yaml
      homekit:
         Camera-Hub-G3-C2C0:
     ```

2. Save the configuration.
3. Restart go2rtc.
4. Open the go2rtc web interface.
5. The HomeKit accessory should appear.

The working installation showed:

```yaml
go2rtc-498F    go2rtc/1.9.14
homekit://192.168.68.81:1984?device_id=1B:C7:A9:32:32:A2&feature=0&status=1
```

"go2rtc-498F" is the HomeKit accessory created by go2rtc.

It is NOT the Aqara G3 itself.

The 192.168.68.81:1984 address is the go2rtc server.

### PAIRING WITH APPLE HOME

On the iPhone:

1. Open the Apple Home app.
2. Tap "+".
3. Select "Add Accessory".
4. Look for the go2rtc HomeKit accessory.
5. Select it.
6. Complete the HomeKit pairing.

The default go2rtc HomeKit PIN is:

`19550224`

If a custom PIN is configured in go2rtc, use that instead.

The default PIN was successfully used in this setup.

### DO NOT DO THIS

Do not add the following URL to Home Assistant:

`homekit://192.168.68.81:1984...`

That URL identifies the go2rtc HomeKit proxy.

It is the accessory that Apple Home should pair with.

### DO NOT USE HOME ASSISTANT'S NORMAL HOMEKIT BRIDGE FOR THE G3

The setup that did NOT work correctly was:

Aqara G3 => Home Assistant => Home Assistant HomeKit Bridge => Apple Home

The camera appeared in Apple Home, but the live stream did not work.

The working setup is:

Aqara G3 =>Home Assistant / HomeKit => go2rtc => go2rtc HomeKit proxy => Apple Home

The Aqara G3 is paired with **Home Assistant**, not directly with Apple Home.

**Result:**

G3 → Home Assistant → go2rtc → Apple Home

The G3 continues to work in Home Assistant through WebRTC.

```yaml

  level: trace
```

   `go2rtc-498F`
4. On the iPhone, open **Apple Home**.
5. Tap **+ → Add Accessory**.
6. Select the **go2rtc** accessory.
7. Enter the go2rtc HomeKit PIN:
   `19550224`
8. Finish the pairing.

### Important

Apple Home should connect to the **go2rtc HomeKit proxy**.
