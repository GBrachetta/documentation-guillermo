# Eve Aqua

Due to the limited connectivity of Eve Aqua to Home Assistant, this is the workaround to keep it on Apple Home and manage it from an automation on Home Assistant.

1. Create a `helper` switch on Home Assistant
    - In HA, go to Settings > Devices & Services > Helpers > Add Helper > Toggle (input_boolean). 
    - Name it something clear, e.g. "Switch Eve Aqua" (entity_id like input_boolean.switch_eve_aqua).

2. Create a `HomeKit` bridge, select to include in it `input_boolean` and add the `helper` switch created in step 1.
3. Pair the HA Bridge into Apple Home
    - HA will show a pairing QR code/PIN for the bridge. In the Apple Home app, tap "+" > Add Accessory > scan the code.
    - This adds a "Home Assistant Bridge" accessory to Apple Home, with your helper appearing inside it as a switch.
4. In the `Eve App`, create a scene. Call it something meaningfull like "Watering Garden"
5. Add the following actions to the scene:
    - Turn **on** the `Eve Aqua`.
    - Turn **off** the `Home Assistant Bridge switch` (the helper created in step 1)

    :::info
    Turning the helper off is important because it will not turn off on its own after the watering is done. 
    The watering will run for the time you set either in the Eve App or the Apple Home configuration for the Eve Aqua. If you don't turn the button off, it will keep in the `on` state and you won't be able to turn it on again until you turn it off manually.
    :::
6. The scene created will appear in Apple Home.
7. Create an automation in **Apple Home** to trigger the scene

    :::info
    When Eve Aqua Garden Turns On, select scene Water Garden
    :::

8. Now you can trigger the watering from Apple Home and also by using the `helper` switch in Home Assistant. 
9. You can now create an automation in Home Assistant to trigger the watering by turning on the `helper` switch based on sensors such as weather, soil moisture, rain in the last 24hs, etc.
10. Automation setup in Home Assistant:

    ```yaml
    alias: Water Garden
    description: ''
    triggers:
      - trigger: time
        at: '08:00:00'
    conditions:
      - condition: numeric_state
        entity_id: sensor.gw1200a_24h_rain
        below: 1
    actions:
      - action: input_boolean.turn_on
        target:
          entity_id: input_boolean.eve_aqua_garden
    mode: single

    ```

**Eve Aqua Control via Home Assistant (Thread bridging workaround)**

Problem: Eve Aqua is Thread-only; direct HomeKit Controller pairing to HA failed with a Thread routing/connectivity error, even after joining HA's OpenThread Border Router (SLZB-MR1) to the same Thread mesh as the Apple border routers.

**Solution**: Indirect control via a HomeKit Bridge helper switch

**HA side**

- Created an input_boolean helper (acts purely as a trigger, not a real status reflection)
- Exposed it to Apple Home via HA's HomeKit Bridge integration
- HA automations trigger the flow by calling input_boolean.turn_on on this helper

**Apple Home side**

- Paired the "Home Assistant Bridge" accessory (shows the helper as a switch)
- Built an Automation: trigger = "helper switch turns on" → action = Run Scene

(Note: Apple's Home app doesn't allow valve/irrigation accessories like Eve Aqua to be selected directly as automation actions — scenes must be used instead)

**Eve app side**

- Since the Home app also restricts Eve Aqua from being added in its own Scene editor, the scene was built in the Eve app instead
- Scene contains 2 actions: (1) start watering, (2) turn the HA helper switch back off
- This makes the helper pulse on/off instantly rather than staying on

**End-to-end flow**

- HA automation → input_boolean.turn_on → HomeKit Bridge → Apple Home automation → Run Eve scene → [watering starts] + [helper resets to off]
- Watering shutoff: Handled entirely by the Eve Aqua's own firmware/timer (10 min default duration) — no HomeKit/HA action needed to turn it back off.
- Limitation: One-directional only — HA can trigger watering, but doesn't receive live status back from the Eve Aqua (would need a second helper + reverse automation for that).
